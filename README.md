# Vicki's Laboratory website

Static site for GitHub Pages. Open `index.html` through a web server (GitHub Pages does this for you).

- `index.html` — the whole site
- `support.js`, `vendor/` — the page runtime (React, Babel), bundled so no external CDN is needed
- `team/`, `gallery/`, `img/` — photos

To update a photo, replace the file with one of the same name and commit.
